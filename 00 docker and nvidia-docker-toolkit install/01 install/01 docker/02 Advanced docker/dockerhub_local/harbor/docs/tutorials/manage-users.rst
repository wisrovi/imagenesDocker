Manage Users and Projects
==========================

Create and manage users, projects, and permissions.

Creating a User
---------------

1. Go to Administration > Users
2. Click "New User"
3. Fill in user details

Creating a Project
------------------

1. Go to Projects
2. Click "New Project"
3. Set project name and access level

Managing Permissions
--------------------

Assign users to projects with appropriate roles:

- Project Admin
- Developer
- Guest
- Limited Guest
