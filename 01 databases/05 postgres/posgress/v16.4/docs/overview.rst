Overview
========

This project provides a comprehensive Docker setup for PostgreSQL 16.4 with additional tools for development and production use.

Features
--------

- PostgreSQL 16.4 with custom extensions
- Connection pooling with PgBouncer
- REST API with PostgREST
- Monitoring with Prometheus and Grafana
- Database migrations with Flyway
- Automated backups
- Caching with Redis
- Web administration with pgAdmin
