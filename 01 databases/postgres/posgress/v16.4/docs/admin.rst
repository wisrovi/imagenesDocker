Administration
==============

pgAdmin interface for database management.

Access
------

- URL: http://localhost:5050
- Username: admin@perseus.com
- Password: admin

Features
--------

- Query editor
- Schema browser
- Backup/restore
- User management
- Performance monitoring

Connecting to Database
----------------------

1. Right-click "Servers" > "Create" > "Server"
2. Name: PostgreSQL
3. Host: postgres
4. Port: 5432
5. Username: perseus
6. Password: (from .env)
