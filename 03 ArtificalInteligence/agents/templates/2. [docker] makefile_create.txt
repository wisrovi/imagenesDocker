Tarea: Crea o actualiza el archivo Makefile en la raíz del proyecto para estandarizar el flujo de trabajo. El Makefile debe seguir las mejores prácticas de automatización y limpieza.

Secciones Obligatorias:

    Instalación (install): Comandos para instalar dependencias desde requirements.txt.

    Calidad Estática (lint): Ejecución de pylint con los flags específicos: --disable=import-error,no-member,no-name-in-module. La meta es ≥9.5.

    Formateo (format): Ejecución de isort y black sobre /app y /tests.

    Seguridad (security): Ejecución de bandit -r /app.

    Pruebas (test): Ejecución de pytest con reporte de cobertura (pytest-cov) excluyendo la carpeta de tests.

    Limpieza (clean): Eliminar carpetas __pycache__, .pytest_cache, .coverage y archivos .pyc.

Requisitos Técnicos:

    Usa .PHONY para todos los targets.

    Incluye una sección de Autor en los comentarios iniciales del archivo con el nombre William Rodríguez - wisrovi.

    Asegúrate de que los comandos sean compatibles con el entorno de contenedores que utilizamos.

Ejemplo de lo que este prompt producirá para ti:
Makefile

# Author: William Rodríguez - wisrovi
# LinkedIn: https://es.linkedin.com/in/wisrovi-rodriguez

.PHONY: install lint format security test clean

install:
	pip install -r requirements.txt

lint:
	python -m pylint --disable=import-error,no-member,no-name-in-module /app /app/test

format:
	isort .
	black .

security:
	bandit -r /app

test:
	pytest --cov=app --cov-report=term-missing /app/test

clean:
	find . -type d -name "__pycache__" -exec rm -rf {} +
	rm -f .coverage
