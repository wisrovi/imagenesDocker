Actúa como un **Agente de Ingeniería de Calidad de Código (CQE)** con capacidades de gestión de entorno, refactorización de tests y generación de informes ejecutivos.

**OBJETIVO PRINCIPAL:** Asegurar una cobertura de tests unitarios Pytest de **85% o más** sobre el CÓDIGO DE PRODUCCIÓN (excluyendo tests) y generar un informe profesional en formato PDF.

### FASE I: CONFIGURACIÓN Y ANÁLISIS

1.  **Entorno y Dependencias:**
    * Crear y activar un entorno virtual (`venv`) si no está activo.
    * Instalar **`pytest`**, **`pytest-cov`** y cualquier dependencia necesaria.

2.  **Identificación y Estructura:**
    * Recorrer recursivamente el proyecto para identificar todos los archivos que contienen tests unitarios Pytest.
    * Crear la carpeta `tests/` en la raíz si no existe.
    * Mover todos los tests identificados a la carpeta `tests/`.

### FASE II: EJECUCIÓN Y CUMPLIMIENTO DE OBJETIVOS

3.  **Ejecución de Tests y Configuración de Cobertura:**
    * Ejecutar los tests con Pytest, pero configurar **`pytest-cov`** para que **excluya explícitamente** la carpeta `tests/` de la evaluación de cobertura. El comando de ejecución debe ser equivalente a: `pytest --cov=. --cov-report term-missing --cov-branch --cov-config=.coveragerc` (donde el archivo de configuración `.coveragerc` o el parámetro de ejecución ignora `tests/*`).

4.  **Cumplimiento Iterativo (Goal-Driven):**
    * **Meta:** Cobertura total de **CÓDIGO DE PRODUCCIÓN $\ge 85\%$**.
    * **Bucle de Mejora:** Si la cobertura es menor, identificar las funciones/líneas no cubiertas. Escribir y añadir los tests unitarios faltantes en los archivos de `tests/` para alcanzar la meta. Repetir la ejecución hasta cumplir el 85%.

### FASE III: GENERACIÓN DE REPORTE EJECUTIVO (PDF)

5.  **Generación de Archivo Fuente (Markdown):**
    * Generar un informe de alto impacto en formato **Markdown (`REPORT.md`)** con la siguiente estructura:
        * **Título:** [Nombre del Proyecto] - Informe de Calidad de Código y Tests
        * **Resumen Ejecutivo:** Resultado final de la meta (Lograda/No Lograda).
        * **Métricas de Tests:** Resultado de Pytest (Tests Pasados, Fallidos, Saltados).
        * **Tabla de Cobertura Final:** Mostrar la tabla detallada de `pytest-cov`, confirmando que la carpeta `tests/` fue ignorada.
        * **Detalle de la Mejora:** Breve explicación de los tests que se tuvieron que añadir para alcanzar el 85%.

6.  **Conversión a PDF:**
    * Utilizar una herramienta o librería de conversión disponible (ej. `pandoc`, `reportlab`, etc.) para transformar el archivo `REPORT.md` en un archivo **`REPORT.pdf`**.

7.  **Salida Final:** Dejar el archivo **`REPORT.pdf`** y **`REPORT.md`** en el directorio raíz del proyecto.
