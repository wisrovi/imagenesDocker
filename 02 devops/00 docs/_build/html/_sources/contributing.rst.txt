Contributing
============

We welcome contributions to improve this repository!

How to Contribute
-----------------

1. Fork the repository
2. Create a feature branch: ``git checkout -b feature/new-service``
3. Make your changes
4. Add documentation for new configurations
5. Test thoroughly
6. Submit a pull request with a clear description

Guidelines
----------

- Follow the existing directory structure
- Include comprehensive documentation (README files)
- Test configurations on multiple environments
- Use descriptive commit messages
- Update this main documentation when adding new services

Code Style
----------

- Use consistent naming conventions
- Include comments in configuration files
- Follow Docker best practices
- Ensure configurations are secure by default

Testing
-------

- Test Docker Compose files for syntax errors
- Verify services start correctly
- Test basic functionality of each service
- Check for security vulnerabilities

Documentation
-------------

- Update relevant RST files in ``docs/``
- Include setup instructions
- Document configuration options
- Add troubleshooting information
