Contribuyendo
=============

.. _contribuyendo:

¡Las contribuciones son bienvenidas! Este documento explica cómo contribuir al proyecto.

Código de Conducta
------------------

Este proyecto sigue el Código de Conducta de Contributor Covenant. Participando, aceptas cumplir con sus términos.

Cómo Contribuir
---------------

1. **Fork el repositorio**
2. **Crea una rama para tu feature**:

   .. code-block:: bash

      git checkout -b feature/nueva-funcionalidad

3. **Realiza tus cambios**
4. **Añade tests si es necesario**
5. **Actualiza la documentación**
6. **Haz commit de tus cambios**:

   .. code-block:: bash

      git commit -m "Añade nueva funcionalidad"

7. **Push a tu fork**:

   .. code-block:: bash

      git push origin feature/nueva-funcionalidad

8. **Crea un Pull Request**

Tipos de Contribuciones
-----------------------

**Código:**

* Nuevas características
* Corrección de bugs
* Optimizaciones de rendimiento
* Mejoras de seguridad

**Documentación:**

* Guías de usuario
* API documentation
* Traducciones
* Ejemplos

**Testing:**

* Tests unitarios
* Tests de integración
* Tests de rendimiento

**Infraestructura:**

* Scripts de CI/CD
* Configuraciones Docker
* Herramientas de desarrollo

Estándares de Código
-------------------

* Usa PEP 8 para Python
* Conventional commits para mensajes
* Documenta funciones y clases
* Añade type hints cuando sea posible

Proceso de Revisión
-------------------

1. Todas las PR requieren revisión
2. Los tests deben pasar
3. La documentación debe estar actualizada
4. Se requiere aprobación de al menos un maintainer

Reportando Issues
-----------------

Para reportar bugs o solicitar features:

1. Verifica que no exista un issue similar
2. Usa las plantillas proporcionadas
3. Incluye información detallada:

   * Versión del proyecto
   * Sistema operativo
   * Pasos para reproducir
   * Comportamiento esperado vs actual

Reconocimientos
---------------

Gracias a todos los contribuidores que han hecho posible este proyecto.
