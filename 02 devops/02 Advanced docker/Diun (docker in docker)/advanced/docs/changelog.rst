Registro de Cambios (Changelog)

.. _changelog:

Versión 1.0.0 (Actual)
----------------------

**Fecha de lanzamiento:** Octubre 2025

**Nuevas características:**

* 🚀 Automatización completa de setup SSH y Portainer
* 🔍 Healthchecks integrados con Docker
* 📚 Documentación completa con Sphinx
* 🐳 Compatibilidad con Docker Compose
* 🔒 Configuraciones de seguridad mejoradas

**Mejoras:**

* Scripts de instalación robustos con manejo de errores
* Tema de documentación profesional (Read the Docs)
* Contenedor dedicado para servir documentación
* Makefile con comandos automatizados

**Correcciones:**

* Problemas de timing en inicialización de servicios
* Conflictos de puertos en configuraciones múltiples
* Errores de permisos en volúmenes persistentes

**Cambios incompatibles:**

* Puerto SSH cambiado a 50422 (era configurable)
* Estructura de directorios reorganizada
