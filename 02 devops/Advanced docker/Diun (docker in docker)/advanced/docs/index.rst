Docker-in-Docker with Portainer and SSH
=====================================

.. image:: _static/logo.png
   :alt: Project logo
   :align: center

A complete Docker-in-Docker environment with Portainer web interface and secure SSH access.

.. note::
   This documentation is in English. For versions in other languages, check the repository.

Main Features
-------------

* 🚀 **Complete Automation**: Automatic SSH and Portainer setup
* 🔒 **Integrated Security**: Secure configurations with health checks
* 📚 **Complete Documentation**: Detailed guides and practical examples
* 🐳 **Full Compatibility**: Based on official Docker images
