Glosario
========

.. _glosario:

Este glosario define términos técnicos utilizados en la documentación.

.. glossary::
   :sorted:

   API
      Application Programming Interface. Interfaz de programación de aplicaciones que permite la comunicación entre diferentes sistemas.

   Bind Mount
      Tipo de montaje en Docker que conecta un directorio del host directamente a un contenedor.

   CI/CD
      Continuous Integration/Continuous Deployment. Prácticas de desarrollo que automatizan la integración y despliegue de código.

   Container
      Instancia ligera y portable de un entorno de ejecución que incluye todo lo necesario para ejecutar una aplicación.

   Daemon
      Proceso en segundo plano que maneja solicitudes de servicio. En Docker, el daemon gestiona contenedores e imágenes.

   DinD
      Docker-in-Docker. Técnica para ejecutar el daemon de Docker dentro de un contenedor Docker.

   Dockerfile
      Archivo de texto con instrucciones para construir una imagen Docker.

   Healthcheck
      Verificación automática del estado de salud de un contenedor o servicio.

   Image
      Plantilla inmutable que contiene el código de la aplicación, librerías y dependencias.

   Namespace
      Característica del kernel Linux que aísla recursos del sistema para procesos específicos.

   OverlayFS
      Sistema de archivos union que permite capas superpuestas, usado por Docker para imágenes.

   Portainer
      Interfaz web de gestión para contenedores Docker.

   Privileged Mode
      Modo especial en Docker que otorga acceso completo al host, necesario para DinD.

   Registry
      Servicio para almacenar y distribuir imágenes Docker.

   SSH
      Secure Shell. Protocolo para acceso remoto seguro a sistemas.

   Swarm
      Modo nativo de clustering en Docker para orquestación de contenedores.

   Volume
      Mecanismo para persistir datos generados por contenedores.

   YAML
      Yet Another Markup Language. Formato de serialización de datos legible por humanos.
